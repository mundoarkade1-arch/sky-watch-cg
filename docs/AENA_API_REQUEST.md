## Assunto sugerido

Solicitação de orientação e autorização para uso de dados de voos do Aeroporto de Campo Grande (CGR/SBCG)

## Mensagem sugerida

Prezados(as),

Estou desenvolvendo o SKY WATCH CG, um aplicativo Android independente para exibir informações de voos de chegada e partida do Aeroporto Internacional de Campo Grande (CGR/SBCG). Atualmente, o aplicativo utiliza registros públicos do SIROS/ANAC somente como horários planejados e não apresenta esses registros como confirmação operacional.

Antes de implementar qualquer informação operacional da Aena/BOAB, gostaria de confirmar por escrito:

1. Qual entidade é responsável pelos dados operacionais de voos de CGR e qual canal deve avaliar este pedido?
2. Existe API, feed ou outra fonte documentada e autorizada para consultar status operacional de voos de CGR? Se existir, poderiam encaminhar a documentação e o procedimento de acesso?
3. É permitido exibir esses dados em um aplicativo independente? Solicitamos as condições aplicáveis a armazenamento, atualização, redistribuição, atribuição da fonte, limites de consulta e apresentação de horários estimados ou confirmados.
4. Quais termos, licenças ou autorizações formais são necessários antes de iniciar uma integração?
5. Caso não exista uma API ou autorização para redistribuição, há uma alternativa oficial que recomendem para orientar o passageiro a confirmar o estado do voo?

Não faremos scraping do site, acesso a endpoints não documentados nem reutilização dos dados operacionais antes de receber orientação e autorização aplicáveis por escrito. Os horários planejados SIROS permanecerão identificados separadamente de qualquer eventual status operacional.

Se esta solicitação não for de responsabilidade deste canal, agradeço o encaminhamento à área responsável por CGR.

Atenciosamente,

Responsável pelo projeto SKY WATCH CG
